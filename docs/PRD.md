# Notion 연동 포트폴리오 사이트 MVP PRD

## 🎯 핵심 정보

**목적**: Notion에 정리해 둔 프로젝트 정보를 웹에서 프로젝트 소개형 포트폴리오로 보여준다
**사용자**: 포트폴리오를 열람하는 방문자(채용담당자, 잠재 클라이언트 등 프로젝트를 살펴보러 오는 외부인)

## 🚶 사용자 여정

```
1. 홈 페이지
   ↓ 대표 프로젝트 카드 클릭 또는 "전체 프로젝트 보기" 클릭

2. [분기]
   [대표 프로젝트 카드 클릭] → 프로젝트 상세 페이지
   [전체 프로젝트 보기 클릭] → 프로젝트 목록 페이지
   ↓

3. 프로젝트 목록 페이지 (전체 프로젝트 카드 그리드)
   ↓ [선택] 기술스택 필터 / 정렬 방향 토글로 목록을 추려 봄
   ↓ 카드 클릭

4. 프로젝트 상세 페이지 (설명, 기술스택, GitHub/데모 링크, 기간 확인)
   ↓ [선택] 이전/다음 프로젝트 클릭 → 인접 프로젝트 상세로 이동 (4단계 반복)
   ↓ 외부 링크 클릭

5. [완료] → GitHub/데모 페이지로 이동
```

## ⚡ 기능 명세

### 1. MVP 핵심 기능

| ID       | 기능명            | 설명                                                       | MVP 필수 이유                             | 관련 페이지                    |
| -------- | ----------------- | ---------------------------------------------------------- | ------------------------------------------ | ------------------------------- |
| **F001** | 프로젝트 목록 조회 | Notion Database에서 프로젝트 목록을 가져와 기간(시작일) 기준 최신순으로 카드형 그리드에 표시 | 포트폴리오의 핵심 진입점                   | 홈, 프로젝트 목록 페이지        |
| **F002** | 프로젝트 상세 조회 | 프로젝트의 설명/기술스택/GitHub 링크/데모 링크/기간을 상세 페이지에 표시 | 방문자가 프로젝트를 실제로 판단하는 핵심 정보 | 프로젝트 상세 페이지            |
| **F003** | 대표 프로젝트 하이라이트 | 홈 화면에 '대표'(Featured 체크박스)로 지정된 프로젝트만 선별 노출 | 첫 방문자에게 핵심 프로젝트를 빠르게 각인 | 홈                               |
| **F004** | 프로젝트 목록 기술스택 필터링 및 정렬 방향 토글 | 프로젝트 목록에서 기술스택(multi-select)으로 프로젝트를 추려 보고, 기간 정렬 방향을 최신순/오래된순으로 전환 | MVP 필수 아님 — 배포 후 확장 | 프로젝트 목록 페이지 |
| **F005** | 프로젝트 상세 이전/다음 프로젝트 네비게이션 | 프로젝트 상세에서 기간 최신순 기준 인접 프로젝트로 바로 이동 | MVP 필수 아님 — 배포 후 확장 | 프로젝트 상세 페이지 |
| **F006** | 홈 프로필 소개 | 홈 상단에 Notion 프로필 페이지의 이름·연락처·소개·기술 스택·학력/교육·수상/자격증을 Notion 본문 순서대로 표시 (전화번호는 공개하지 않음) | MVP 필수 아님 — 배포 후 확장 | 홈 |

> F004~F006은 MVP 배포 이후 사용자 요청으로 추가된 확장 기능이며, 요구사항 추적 편의를 위해 같은 표에서 관리한다.

### 2. MVP 이후 기능 (제외)

아래 항목은 현재 범위 밖이다. (MVP 이후 기능이지만 사용자 요청으로 예외 진행하는 F004~F006은 위 핵심 기능 표로 이동했다.)

- 블로그/노트 페이지 (Notion 글을 블로그 형태로 노출)
- 프로젝트 카테고리/태그 검색 (기술스택 필터링은 F004로 별도 진행하며, 키워드 검색 기능은 계속 제외)
- 필터/정렬 상태의 URL 쿼리 동기화 및 공유 가능한 필터 링크 (F004는 페이지 내 일시 상태만 유지)
- 소개(About) 전용 페이지 (별도 요청 시 추가. 홈 안의 프로필 섹션은 F006으로 별도 진행)
- 로그인/관리자 기능 (콘텐츠 수정은 Notion에서 직접 수행하므로 불필요)
- 다국어 지원
- Contact/문의 페이지 (기존 스타터킷 예시 페이지이며, 포트폴리오 핵심 범위 아님)

## 📱 메뉴 구조

```
📱 포트폴리오 내비게이션 (화면 하단에 떠 있는 플로팅 독)
├── 🏠 홈
│   └── 기능: F003 (대표 프로젝트 하이라이트), F006 (홈 프로필 소개)
└── 📂 프로젝트
    └── 기능: F001 (프로젝트 목록 조회), F004 (기술스택 필터링 및 정렬 방향 토글)

🌓 테마 전환 (메뉴 항목이 아님: 모든 페이지 우상단 버튼, Light / Dark / System)
```

> 내비게이션은 상단 헤더 없이 화면 하단의 둥근 독(홈, 프로젝트) 하나로 제공한다. 현재 페이지에 해당하는 탭(프로젝트 상세에서는 "프로젝트")이 강조되며, 탭을 이동하면 강조 표시가 미끄러지듯 따라간다(모션 감소 설정 시 비활성). 테마 전환은 자주 쓰지 않는 설정이라 독에 넣지 않고 페이지 우상단에 두며, 화면에 고정하지 않고 페이지와 함께 스크롤된다.

> 프로젝트 상세 페이지는 별도 메뉴 항목이 아니며, 홈/프로젝트 목록 페이지의 카드 클릭 또는 다른 프로젝트 상세의 이전/다음 네비게이션(F005)을 통해 진입한다.

| **다음 이동**  | 대표 프로젝트 카드 클릭 → 프로젝트 상세 페이지, "전체 프로젝트 보기" 클릭 → 프로젝트 목록 페이지 |

## 🗄️ 데이터 모델

### Project (Notion Database — 포트폴리오 프로젝트)

| 필드     | 설명                    | 타입/관계        |
| -------- | ----------------------- | ---------------- |
| id       | 고유 식별자              | Notion Page ID    |
| 제목     | 프로젝트 이름            | title             |
| 요약     | 한 줄 소개               | rich text         |
| 설명     | 프로젝트 상세 설명       | Notion 페이지 본문 |
| 기술스택 | 사용한 기술 목록         | multi-select      |
| GitHub 링크 | GitHub 저장소 URL    | url               |
| 데모 링크 | 데모 페이지 URL         | url               |
| 썸네일   | 대표 이미지              | files & media     |
| 기간     | 프로젝트 진행 기간       | date range        |
| 대표     | 홈 화면 하이라이트 노출 여부 | checkbox      |

### Profile (Notion 페이지 — 홈 프로필, F006)

환경변수 `NOTION_PROFILE_PAGE_ID`(선택)가 가리키는 페이지 하나로 관리한다. 값이 없거나 조회에 실패하면 홈은 기존 소개 문구를 보여준다.

| 항목     | 설명                                         | 타입/관계                                        |
| -------- | -------------------------------------------- | ------------------------------------------------ |
| 이름     | 홈 상단 제목(h1)                             | 페이지 제목(title)                               |
| 본문     | 연락처, 소개, 학력/교육, 수상/자격증          | 페이지 본문 블록(제목·문단·목록·링크), 작성 순서 그대로 노출 |
| 기술 스택 | 본문 중간에 둔 인라인 DB의 행(분야별)         | 하위 Database: `구분`(title), `많이 해봤어요`·`해본 적 있어요`(multi-select) |

## 🛠️ 기술 스택 (현재 저장소 기준 최신 버전)

### 🎨 프론트엔드 프레임워크

- **Next.js 16** (App Router, Turbopack 기본) - React 풀스택 프레임워크
- **TypeScript 5.6+** - 타입 안전성 보장
- **React 19** - UI 라이브러리 (최신 동시성 기능)

### 🎨 스타일링 & UI

- **TailwindCSS v4** (설정파일 없는 CSS-first 엔진) - 유틸리티 CSS 프레임워크
- **shadcn/ui** (`base-nova` 스타일, Base UI 프리미티브 기반) - 고품질 React 컴포넌트 라이브러리
- **Lucide React** - 아이콘 라이브러리
- **next-themes** - 라이트/다크/시스템 테마 전환 (기존 구성 유지)

### 🔗 CMS 연동

- **Notion 공식 API (`@notionhq/client`)** - 프로젝트 목록/상세 데이터 조회
- **Notion 블록 렌더러** - 프로젝트 상세 설명(Notion 페이지 본문)을 웹 화면에 표시

### 🚀 배포 & 호스팅

- **Vercel** - Next.js 16 최적화 배포 플랫폼

### 📦 패키지 관리

- **npm** - 의존성 관리
