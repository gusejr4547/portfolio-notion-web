# Notion 연동 포트폴리오 사이트 MVP PRD

## 🎯 핵심 정보

**목적**: Notion에 정리해 둔 프로젝트 정보를 웹에서 프로젝트 소개형 포트폴리오로 보여준다
**사용자**: 포트폴리오를 열람하는 방문자(채용담당자, 잠재 클라이언트 등 프로젝트를 살펴보러 오는 외부인)

## 🚶 사용자 여정

```
1. 홈 페이지
   ↓ 대표 프로젝트 카드 클릭 또는 "전체 프로젝트 보기" 클릭

2. [분기]
   [대표 프로젝트 카드 클릭] → 프로젝트 상세 페이지
   [전체 프로젝트 보기 클릭] → 프로젝트 목록 페이지
   ↓

3. 프로젝트 목록 페이지 (전체 프로젝트 카드 그리드)
   ↓ 카드 클릭

4. 프로젝트 상세 페이지 (설명, 기술스택, GitHub/데모 링크, 기간 확인)
   ↓ 외부 링크 클릭

5. [완료] → GitHub/데모 페이지로 이동
```

## ⚡ 기능 명세

### 1. MVP 핵심 기능

| ID       | 기능명            | 설명                                                       | MVP 필수 이유                             | 관련 페이지                    |
| -------- | ----------------- | ---------------------------------------------------------- | ------------------------------------------ | ------------------------------- |
| **F001** | 프로젝트 목록 조회 | Notion Database에서 프로젝트 목록을 가져와 기간(시작일) 기준 최신순으로 카드형 그리드에 표시 | 포트폴리오의 핵심 진입점                   | 홈, 프로젝트 목록 페이지        |
| **F002** | 프로젝트 상세 조회 | 프로젝트의 설명/기술스택/GitHub 링크/데모 링크/기간을 상세 페이지에 표시 | 방문자가 프로젝트를 실제로 판단하는 핵심 정보 | 프로젝트 상세 페이지            |
| **F003** | 대표 프로젝트 하이라이트 | 홈 화면에 '대표'(Featured 체크박스)로 지정된 프로젝트만 선별 노출 | 첫 방문자에게 핵심 프로젝트를 빠르게 각인 | 홈                               |

### 2. MVP 이후 기능 (제외)

- 블로그/노트 페이지 (Notion 글을 블로그 형태로 노출)
- 프로젝트 카테고리/태그 필터링 및 검색
- 소개(About) 전용 페이지 (별도 요청 시 추가)
- 로그인/관리자 기능 (콘텐츠 수정은 Notion에서 직접 수행하므로 불필요)
- 다국어 지원
- Contact/문의 페이지 (기존 스타터킷 예시 페이지이며, 포트폴리오 핵심 범위 아님)

## 📱 메뉴 구조

```
📱 포트폴리오 내비게이션
├── 🏠 홈
│   └── 기능: F003 (대표 프로젝트 하이라이트)
└── 📂 프로젝트
    └── 기능: F001 (프로젝트 목록 조회)
```

> 프로젝트 상세 페이지는 별도 메뉴 항목이 아니며, 홈/프로젝트 목록 페이지의 카드 클릭을 통해서만 진입한다.

## 📄 페이지별 상세 기능

### 홈

> **구현 기능:** `F003` | **메뉴 위치:** 헤더 "홈"

| 항목           | 내용                                                                                     |
| -------------- | ---------------------------------------------------------------------------------------- |
| **역할**       | 방문자에게 첫인상을 주는 랜딩 페이지, 대표 프로젝트를 빠르게 소개                          |
| **진입 경로**  | 사이트 최초 접속 시 기본 진입, 헤더의 "홈" 메뉴 클릭                                      |
| **사용자 행동** | 소개 문구를 읽고 대표 프로젝트 카드를 훑어봄                                              |
| **주요 기능**  | • 소개 문구/타이틀 노출<br>• '대표'(Featured)로 체크된 프로젝트 카드만 노출 (체크된 프로젝트가 없으면 기간 기준 최신 프로젝트로 대체 노출)<br>• **전체 프로젝트 보기** 버튼 |
| **다음 이동**  | 대표 프로젝트 카드 클릭 → 프로젝트 상세 페이지, "전체 프로젝트 보기" 클릭 → 프로젝트 목록 페이지 |

---

### 프로젝트 목록

> **구현 기능:** `F001` | **메뉴 위치:** 헤더 "프로젝트"

| 항목           | 내용                                                                 |
| -------------- | ---------------------------------------------------------------------- |
| **역할**       | 등록된 모든 프로젝트를 한눈에 훑어볼 수 있는 목록 페이지                 |
| **진입 경로**  | 헤더의 "프로젝트" 메뉴 클릭, 홈의 "전체 프로젝트 보기" 버튼 클릭        |
| **사용자 행동** | 카드 형태로 나열된 프로젝트들을 스크롤하며 살펴보고 관심 있는 카드를 클릭 |
| **주요 기능**  | • Notion Database 기반 프로젝트 카드 그리드<br>• 기간(시작일) 기준 최신순 정렬<br>• 카드별 썸네일/제목/요약 노출 |
| **다음 이동**  | 카드 클릭 → 프로젝트 상세 페이지                                        |

---

### 프로젝트 상세

> **구현 기능:** `F002` | **진입 조건:** 홈 또는 프로젝트 목록 페이지의 카드 클릭 (메뉴 직접 노출 없음)

| 항목           | 내용                                                                                                     |
| -------------- | ---------------------------------------------------------------------------------------------------------- |
| **역할**       | 하나의 프로젝트를 깊이 있게 소개하는 상세 페이지                                                            |
| **진입 경로**  | 홈 또는 프로젝트 목록 페이지의 프로젝트 카드 클릭                                                           |
| **사용자 행동** | 프로젝트 설명, 기술스택, 진행 기간을 확인하고 GitHub 저장소 또는 데모 페이지로 이동                          |
| **주요 기능**  | • 제목/기간 노출<br>• 상세 설명(Notion 본문) 렌더링<br>• 기술스택 뱃지 목록<br>• **GitHub 링크** 버튼<br>• **데모 링크** 버튼 (데모 링크가 없는 프로젝트는 버튼 숨김) |
| **다음 이동**  | GitHub 링크 클릭 → GitHub 저장소(새 탭), 데모 링크 클릭(있는 경우) → 데모 페이지(새 탭)                        |

## 🛠️ 기술 스택 (현재 저장소 기준 최신 버전)

### 🎨 프론트엔드 프레임워크

- **Next.js 16** (App Router, Turbopack 기본) - React 풀스택 프레임워크
- **TypeScript 5.6+** - 타입 안전성 보장
- **React 19** - UI 라이브러리 (최신 동시성 기능)

### 🎨 스타일링 & UI

- **TailwindCSS v4** (설정파일 없는 CSS-first 엔진) - 유틸리티 CSS 프레임워크
- **shadcn/ui** (`base-nova` 스타일, Base UI 프리미티브 기반) - 고품질 React 컴포넌트 라이브러리
- **Lucide React** - 아이콘 라이브러리
- **next-themes** - 라이트/다크/시스템 테마 전환 (기존 구성 유지)

### 🔗 CMS 연동

- **Notion 공식 API (`@notionhq/client`)** - 프로젝트 목록/상세 데이터 조회
- **Notion 블록 렌더러** - 프로젝트 상세 설명(Notion 페이지 본문)을 웹 화면에 표시

### 🚀 배포 & 호스팅

- **Vercel** - Next.js 16 최적화 배포 플랫폼

### 📦 패키지 관리

- **npm** - 의존성 관리

- [x] 기능 명세에서 명시한 관련 페이지(홈, 프로젝트 목록, 프로젝트 상세)가 모두 페이지별 상세 기능에 존재함
- [x] 메뉴 구조의 모든 항목(홈, 프로젝트)이 페이지별 상세 기능에 해당 페이지로 존재함
- [x] 메뉴에서 참조하는 기능 ID(F003, F001)가 모두 기능 명세에 정의됨
- [x] 페이지별 상세 기능의 모든 구현 기능 ID가 기능 명세에 정의됨
- [x] 모든 페이지가 메뉴 구조 또는 다른 페이지 내 이동(카드 클릭)을 통해 접근 가능함 (프로젝트 상세는 홈/프로젝트 목록에서 접근)
- [x] 기능 명세에만 있고 페이지에서 구현되지 않은 기능 없음
- [x] 페이지에만 있고 기능 명세에 정의되지 않은 기능 없음

- [x] F002(프로젝트 상세 조회)에서 언급하는 GitHub/데모 링크가 데이터 모델의 `GitHub 링크`/`데모 링크` 필드와 1:1로 대응함
